# TryHackMe Write-ups

This directory documents my learning and progress through authorized cybersecurity rooms on TryHackMe.

The platform provides practical exercises that help reinforce cybersecurity concepts through guided learning and hands-on challenges.

## Learning Focus

- Network reconnaissance
- Linux fundamentals
- Cybersecurity fundamentals
- Enumeration and service discovery
- Basic security investigation
- Beginner-friendly CTF challenges

## Write-up Structure

Each room write-up may contain:

- Room name and learning objectives
- Key concepts learned
- Tools and commands used
- Investigation process
- Challenge solution, where permitted
- Lessons learned

## Learning Notes

I aim to explain not only how I completed a task, but also why a particular command or technique works.

Write-ups will be added as I complete rooms and review the concepts involved.

**Note:** Spoilers and challenge answers will be clearly identified where appropriate.
