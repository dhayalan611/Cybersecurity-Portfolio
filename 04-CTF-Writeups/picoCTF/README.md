# picoCTF Write-ups

This directory contains notes from picoCTF challenges completed as part of my cybersecurity practice.

picoCTF provides hands-on challenges that help learners develop technical problem-solving skills across different security domains.

## Learning Focus

- General skills and command-line tools
- Cryptography fundamentals
- Web exploitation concepts
- Digital forensics
- Binary exploitation fundamentals
- Reverse engineering fundamentals

The topics covered will depend on the challenges I complete and my current skill level.

## Write-up Structure

Each write-up may include:

- Challenge name and category
- Problem description
- Initial observations
- Tools and commands used
- Step-by-step reasoning
- Solution and explanation
- Key takeaways

## Learning Approach

I use challenges to strengthen my understanding rather than simply collect flags. I aim to explain the reasoning behind each solution and record techniques that may be useful in future challenges.

*New write-ups will be added as challenges are completed.*
