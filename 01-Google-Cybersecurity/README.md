
# Google Cybersecurity Certificate

## 📌 Overview

This directory documents my learning journey through the Google Cybersecurity Certificate on Coursera.

The course introduces core cybersecurity concepts, security practices, risk management, Linux, SQL, networking, and security operations. I use this directory to organise my course notes, practical exercises, and portfolio assignments.

## 🎯 Learning Objectives

- Understand fundamental cybersecurity concepts and terminology.
- Identify security risks, threats, and vulnerabilities.
- Learn how security controls help protect organisational assets.
- Develop foundational Linux and SQL skills for security tasks.
- Understand network security and security monitoring.
- Build a foundation for entry-level cybersecurity and SOC analyst roles.

- Network protocols and communication

- Network security fundamentals

### 4. Linux and SQL
- Linux commands and file management
- Navigating directories and managing permissions

- Incident investigation and response fundamentals
