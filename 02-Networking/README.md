# Networking

This section documents my networking learning journey as part of my cybersecurity studies.

Understanding networking is essential for identifying suspicious activity, analyzing network traffic, troubleshooting connectivity, and investigating security incidents.

## Topics Covered

- Networking fundamentals and network models
- TCP/IP and OSI models
- IPv4 addressing and subnetting
- Common protocols and ports
- DNS, DHCP, HTTP/HTTPS, TCP and UDP
- Network scanning and host discovery
- Network traffic analysis

## Tools

- **Nmap** — Network discovery and port scanning
- **Wireshark** — Network packet capture and analysis
- **Cisco Packet Tracer** — Network design and simulation
