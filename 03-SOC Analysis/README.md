# SOC Analysis

This section focuses on Security Operations Center (SOC) fundamentals and the techniques used to monitor, detect, analyze, and investigate potential security incidents.

My goal is to develop practical skills relevant to entry-level security operations and cybersecurity analyst roles.

## Topics Covered

- Security logs and event analysis
- Security Information and Event Management (SIEM)
- Alert triage and investigation
- Indicators of Compromise (IoCs)
- Incident detection and response
- Authentication and access logs
- Basic threat hunting concepts

## Learning Objectives

- Understand why logs are important in security investigations
- Recognize suspicious patterns in event data
- Learn how SIEM platforms collect and correlate events
- Practice investigating alerts using available evidence
- Document findings clearly and explain recommended actions
